一份**主观**的啤酒品鉴记录：喝了什么、什么味道、值不值得再买。

数据全部放在 [`data/beers.yml`](data/beers.yml)，本页的统计和酒单由脚本自动生成，方便长期维护，也方便别人提交自己的品鉴。

## 评分与价格说明

评分完全主观，只代表「我还想不想再喝」。

| 评分 | 含义 |
| :---: | --- |
| ★★★★★ | 会主动回购，愿意推荐给朋友 |
| ★★★★☆ | 好喝，值得再买 |
| ★★★☆☆ | 一般，能喝但不惦记 |
| ★★☆☆☆ | 不太行，喝完不会想第二瓶 |
| ★☆☆☆☆ | 踩雷 |

价格档位：`¥` 平价 · `¥¥` 适中 · `¥¥¥` 偏贵（各地、各渠道差异很大，仅供参考）。

## 本地使用

只需要 Python 3.9+ 和 PyYAML：

```bash
pip install pyyaml

python scripts/build.py          # 修改 data/beers.yml 后重新生成 README
python scripts/build.py --check  # 只检查 README 是否最新
```

数据格式与字段含义见 [`CONTRIBUTING.md`](CONTRIBUTING.md)，JSON Schema 在 [`schema/beer.schema.json`](schema/beer.schema.json)。

## 参与贡献

欢迎提交 PR 补充你喝过的酒，或者直接开 [Issue](../../issues/new/choose) 告诉我哪一条你不认同。流程很短：

1. Fork 仓库，新建分支；
2. 在 `data/beers.yml` 末尾追加条目（`id` 不要重复）；
3. 运行 `python scripts/build.py`；
4. 提交 PR，CI 会自动校验数据格式。

具体字段说明和示例见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。

## 免责声明

- 所有评价都基于个人口味，同一款酒不同批次、不同温度、不同杯子都可能不一样；
- 酒精度、麦汁浓度等参数优先采用包装标注，笔记里没记的留空（`null`），不做推测；
- 理性饮酒，未成年人请勿饮酒，喝酒不开车。
